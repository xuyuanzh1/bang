# bang
我构建了一个基于 LangGraph 的多 Agent 智能合同审阅系统——ContractGuard。核心痛点：企业法务团队处理海量供应商合同时，人工审阅效率低、高风险条款（如无限连带责任、隐蔽的违约金条款）极易遗漏。核心逻辑流融合长链推理与多 Agent 协作：用户上传合同 PDF 后，解析 Agent 提取结构化文本并定位条款边界；随后四个专项风险 Agent（付款条款、违约责任、知识产权、保密条款）并行执行各自的推理链——先定位相关语句，再对照内部规则库与司法判例进行语义矛盾检测，生成初步风险评分与修订建议；所有结果汇集至仲裁 Agent，进行跨条款的冲突消解与综合评级（例如发现付款账期与违约罚则存在逻辑矛盾），最终输出一份带高亮风险点及一键修改方案的综合报告。
